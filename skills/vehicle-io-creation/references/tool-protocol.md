# Assembly tool protocol

The backend supplies the authoritative versioned JSON schema from car2lego3d.assembly_protocol.protocol(), plus its hash. Responses contain tool, arguments_json and reason. arguments_json is a JSON-encoded object; the host validates it before execution. The finish action stops planning and triggers host validation, never automatic acceptance.

- inspect: page the instance graph, revision and BOM.
- context: read exact resource pages with RFC 6901 pointers, offsets and at most 400 characters per page; follow next_offset until complete. Full requests, schemas, observations and errors remain available without truncation.
- remember: persist a work note of at most 128 characters across decisions; keep exact large values in their source resources.
- query_part: obtain native bounds, geometry, connector and collision evidence.
- query_module: read a retrieved module's native bounds and BOM without changing the assembly; inspect its full graph through the returned context resource.
- retrieve: search model/submodel names and brand/category tags with optional min_parts/max_parts bounds, subject to host-owned held-out exclusions. types filters vehicle body categories, not module kinds; omit it unless known. Empty results include diagnostics with available categories and recovery guidance, without relaxing filters or exclusions. Inspect native geometry and interfaces before selecting a candidate; size and name hints do not establish structural validity.
- edit: revision-checked atomic module/add/remove/replace/color/transform/joint operations. Module names end in .ldr. Module/add aliases can be used as @alias parent/instance references later in the same batch; the result maps aliases to real instance IDs.
- graft: transplant a retrieved module with hierarchy and dependencies.
- snap: align verified compatible source/target ports with rigid transforms.
- search_mounts (v8): read-only search for an existing moving part/subtree against target part/module roots outside it. Required revision,moving,targets; optional limit=6 (max20), max_evaluations=64 (max256), max_port_pairs=20000 (max100000), max_axial_samples=9 (1..33), source_ports and target_ports arrays of {instance,port}. Returns exact native contacts, axial offsets and build_arguments including the moved root joint. Search covers 24 relative axis rotations, native overlap-maximizing seating first, then bounded shaft insertion-interval samples respecting native stops, minimum engagement and keys. Set max_axial_samples=1 to disable alternatives. No new adapters or exhaustive continuous search. All candidates share the evaluation budget. No global collisions, missing native evidence, invalid transforms or protected changes are accepted; all moving parts must join the selected target component. Other disconnected components remain visible in whole_graph and force draft strict=false replay. Vehicle wheel layout is checked for installed wheels; motion and final completeness remain separate. Reports bind the base graph, bindings and native dependencies. Budget exhaustion and no proposals are not proof of impossibility.
- attach (v4): add and snap a new standard part in one atomic revision using observed part/port IDs. Supply revision, part, source_port, target and target_port; optional parent, color and initial matrix preserve native orientation. The default strict=true rejects failed or incomplete native checks and rolls back the entire addition. Use strict=false only for an explicitly unfinished draft and run check afterward. This operation does not accept invented ports or scaled geometry.
- axial_clearance (v10): read-only continuous native-OBB sweep at an already engaged shaft contact. Required revision,moving,source,source_port,target,target_port. Source belongs to moving; target stays outside. max_travel=400 LDU (maximum 2000), max_pairs=100000 (maximum 100000). Both directions extend beyond the entire selected port intervals. Returns clear/blocked/unverified with first collider blockers and source hashes. Initial cross-subtree interference, missing colliders, changed evidence and incomplete pair budgets cannot establish a clear path; a travel limit without an observed blocker remains unverified. Fixed-orientation continuous SAT avoids translation sampling gaps within the stated collision tolerance. Connector cap flags are reported but do not substitute for collider geometry. Other contacts, rotation, alternative release paths, friction, deformation, retention strength and load are outside scope. No physical retention pass is issued.
- build (v5): execute 1..64 edit/attach/snap operations atomically at the current revision. Read guide:/build_operations/<op> for exact signatures. Module/add/attach may declare aliases; earlier aliases resolve as @name in parent/instance/source/target/moving. A complete strict native check runs before publishing one revision. Any failed operation or final check restores the previous graph. strict=false is an explicit unfinished draft, never an acceptance override. Retain returned real aliases for subsequent calls.
- articulate (v6): declare a joint at an existing exact native axle/hinge contact. Supply revision, instance, source, source_port, target, target_port, limits and purpose; type defaults to revolute. Source belongs to the moving subtree, target stays outside. The host converts the target port's native axis/origin into the moving instance's parent frame. Supports standalone calls and build operations with aliases. Revolute values are degrees, prismatic values are LDU; rolling requires a revolute 360-degree span. Run motion to verify clearance and persistent connectivity; creating the joint is not acceptance.
- check and motion: inspect static and moving assemblies. check may include bounded shaft_diagnostics with actual world endpoints, axis alignment, lateral error, axial gap and engagement for disconnected components. Those repair hints do not change any validation gate or certify an insertion. Joint purposes identify the steering/suspension combinations. Single-joint sweeps use at least nine samples and refine around collisions; all declared steering/suspension pairs also receive combined samples. Unnamed joint purposes and unavailable evidence remain unverified. Other unsampled multi-joint combinations and physical durability remain outside this measurement.
- bind_module (v2): use the current revision, a required vehicle_contract module key, actual submodel roots and a map of required role names to distinct part instance IDs. Changes invalidate prior checks and review. No planner-supplied completeness ratings are accepted.
- module_progress (v2): inspect actual bindings, geometry/connector coverage, external interface contacts, door/glass ownership, joint purposes and at least nine poses, plus independent host role evidence. The host may review a structurally ready export when finish is requested. It cannot complete a structurally incomplete assembly. Exporting a draft remains possible at any point.
- render: export the resolved native graph to GLB; this alone does not show an image to the planner.
- preview (v5): render six complete native-geometry views and a contact sheet. The host binds pixels, graph, revision, native dependencies, materials and renderer hashes. Current images are attached to the vision planner; text planners receive paths only. Changed geometry or evidence invalidates the preview. Inspect actual views after check and before export; a successful render does not establish appearance acceptance.
- export: produce portable model artifacts.

Coordinates are LDraw/LDU. A standard brick height is 24 LDU; one stud pitch is 20 LDU; one LDU is 0.0004 metres. Matrices are local homogeneous 4x4 matrices. Convert explicitly for Blender. Use current revisions and observed instance and port IDs. Failed edits roll back. Read the error before retrying.

Check and motion reports include graph_sha256 and evidence_files. Results expire when exact native dependency bytes change, including a previously missing file appearing. Module progress also binds role assignments and check/review evidence. Motion poses require connection evidence; collision-free detachment fails. The delivery report binds its inspected outputs and review files separately from planner status.

Example read decision:

    {"tool":"inspect","arguments_json":"{\"offset\":0,\"limit\":50}","reason":"Read the current revision and module structure"}
# Module candidate trials

`candidate(revision,module,label)` measures a real bound module, saves its complete assembly state and native evidence, and fingerprints its part identities and relative rigid transforms. Three distinct passing structures are required by the module host. Unknown data cannot qualify. `restore_candidate(revision,module,candidate)` restores a captured trial only if the surrounding assembly and evidence are unchanged. Restoration advances the revision and invalidates prior checks. These operations do not certify part-role semantics, appearance or physical buildability.
